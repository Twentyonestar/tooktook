# 실기기 QA 체크리스트

툭툭가계부 MVP를 실제 iPhone에서 검증하기 위한 절차. 시뮬레이터 통과는 실기기 검증으로 치지 않는다.

- 대상 기기: iPhone 15 Pro (무료 개인 팀 서명, 설치 후 7일 만료)
- 기록 규칙: 결과는 `통과` / `실패` / `미검증` 중 하나. 통과·실패에는 날짜, 커밋, 근거를 적는다.
- 근거 수집: 앱 데이터는 Mac에서 아래 명령으로 복사해 SQLite로 확인할 수 있다.

```bash
xcrun devicectl device copy from --device <기기 ID> --domain-type appDataContainer --domain-identifier com.twentyonestar.tooktook --source "Library/Application Support/default.store" --destination ./default.store
```

(`default.store-wal`, `default.store-shm`도 같은 방법으로 함께 복사해야 최신 내용이 보인다.)

## 사전 준비

1. 최신 `feat/mvp-scaffold` 빌드를 설치한다.
2. 단축어 앱에 '스택 남기기' 단축어가 있고, 설정 › 손쉬운 사용 › 터치 › 뒷면 탭 › 이중 탭에 연결돼 있는지 확인한다.
3. 툭툭가계부 설정에서 위치 권한과 알림 권한 상태를 기록해 둔다.

## 항목별 절차

### 1. Back Tap → 스택 생성
1. 홈 화면에서 뒷면을 두 번 탭한다.
2. 기대: 1초 안팎으로 "오후 ○○:○○ 스택을 남겼어요" 배너. 앱 화면은 열리지 않는다.
3. 앱을 열어 인박스 맨 아래에 방금 시각의 스택이 있는지 확인한다.

### 2. 잠금 상태 Back Tap
1. 화면을 잠근다(측면 버튼). 화면이 꺼진 상태와 잠금화면이 켜진 상태 두 경우를 각각 시험한다.
2. 뒷면을 두 번 탭한다.
3. 잠금을 풀고 앱을 열어 스택이 생겼는지, 위치 상태가 무엇인지 기록한다.
- 기록할 것: 스택 생성 여부, 배너 표시 여부, 위치 저장 여부(잠금 상태에서는 위치가 실패할 수 있음)

### 3. 위치 허용 상태에서 좌표 수집
1. 설정 › 개인정보 보호 › 위치 서비스 › 툭툭가계부 = "앱을 사용하는 동안".
2. 실외와 실내에서 각각 Back Tap.
3. 앱 인박스에서 장소명 또는 상태 문구를 확인하고, 필요하면 DB에서 정확도를 확인한다.

### 4. 장소명 자동 표시
다음 세 상황에서 각각 스택을 만들고 장소명이 붙는지 본다.
1. 앱이 열려 있는 상태에서 Back Tap → 화면에 바로 반영되는지
2. 앱을 백그라운드로 보낸 뒤 Back Tap → 앱으로 돌아왔을 때 반영되는지
3. 앱을 완전히 종료한 뒤 Back Tap → 앱을 새로 열었을 때 반영되는지
- 기대 문구: "서울특별시 ○○구 ○○동"(정확도 100m 이하), "서울특별시 ○○구"(100~500m), "위치 정확도 낮음"(500m 초과)

### 5. 위치 권한 거부
1. 위치 권한을 "안 함"으로 바꾼다.
2. Back Tap → 스택이 생성되고 "위치 확인 불가"가 표시되는지 확인한다.
3. 권한을 되돌린 뒤 기존 스택에 현재 위치가 붙지 않는지 확인한다.

### 6. 네트워크 오프라인
1. 위치는 허용한 채 비행기 모드를 켠다(GPS는 동작할 수 있음).
2. Back Tap → 스택 생성 확인. 장소 문구가 "장소 확인 중" 또는 "장소 확인 대기 중 · 다시 시도할게요"인지 확인한다.
3. 비행기 모드를 끄고 앱을 다시 활성화한다 → 장소명이 붙는지 확인한다.
4. 3회 실패 후 "위치는 저장됨 · 장소 확인 불가"가 뜨면 정리 화면의 "장소 다시 확인"을 눌러 본다.

### 7. 사용자 지정 시간 알림 수신
1. 설정에서 알림 시각을 지금부터 3~5분 뒤로 바꾼다.
2. 미정리 스택이 1개 이상 있는 상태로 앱을 백그라운드로 보낸다.
3. 지정 시각에 "오늘의 스택 정리 · 정리하지 않은 스택이 N개 있어요" 알림이 오는지 확인한다.

### 8. 알림 탭 → 스택 인박스 이동
1. 7번 알림을 앱이 다른 탭(통계 등)에 있는 상태에서 받는다.
2. 알림을 눌러 스택 탭이 열리는지 확인한다.

### 9. 미정리 0개 시 알림 취소
1. 알림 시각을 몇 분 뒤로 설정하고, 미정리 스택을 모두 정리하거나 삭제한다.
2. 지정 시각에 알림이 오지 않는지 확인한다.

### 10. 앱 강제 종료 상태에서 단축어 실행
1. 앱 전환기에서 툭툭가계부를 위로 밀어 종료한다.
2. Back Tap → 스택 생성 배너 확인.
3. 앱을 열어 스택과 장소명을 확인한다.

### 11. JSON 백업 내보내기·가져오기
1. 설정 › 기록 내보내기 → 파일 앱에 저장한다.
2. 스택 1개를 새로 만든다.
3. 설정 › 기록 가져오기 → 방금 파일 선택 → 확인 창에 현재/백업 건수와 "현재 데이터 먼저 내보내기"가 보이는지 확인한다.
4. 가져오기 후 2번에서 만든 스택이 사라지고 백업 시점 데이터로 돌아가는지 확인한다.
5. 같은 파일을 한 번 더 가져와도 건수가 늘지 않는지 확인한다.

### 12. 큰 글씨·VoiceOver
1. 설정 › 손쉬운 사용 › 디스플레이 및 텍스트 크기 › 더 큰 텍스트를 최대로 한다.
2. 인박스, 정리 화면, 온보딩 3단계(알림 시각), 설정에서 글자가 잘리거나 겹치지 않는지 본다.
3. VoiceOver를 켜고 인박스 행, 카테고리 선택, 금액 입력, "모두 정리하기"가 의미 있게 읽히는지 확인한다.

### 13. 라이트·다크 모드
1. 앱 설정의 화면 모드를 라이트/다크/시스템으로 바꿔 각 탭과 온보딩을 확인한다.

### 14. 자정·월 경계 갱신
1. 23:58쯤 앱 인박스를 열어 둔 채 기다린다.
2. 00:00 이후 "오늘 남긴 미정리 스택"이 0으로 바뀌고 어제 스택은 날짜가 붙어 남아 있는지 확인한다.
3. 월말에는 통계 탭이 새 달로 넘어가는지 확인한다.

### 15. 알림 권한 재허용 시 예약 복구
1. iPhone 설정에서 툭툭가계부 알림을 끈다 → 앱 설정에 "정리 알림이 꺼져 있어요"가 보이는지 확인한다.
2. "알림 설정 열기"로 이동해 알림을 다시 켜고 앱으로 돌아온다.
3. 안내가 사라지고, 저장된 시각에 알림이 오는지 7번 절차로 확인한다.
