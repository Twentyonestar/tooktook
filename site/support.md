# 툭툭가계부 지원

결제할 때 iPhone 뒷면을 두 번 두드려 시각(과 위치)을 '스택'으로 남기고, 금액과 카테고리는 하루 끝에 몰아서 정리하는 가계부예요. 회원가입이 없고 모든 기록은 iPhone 안에만 저장돼요.

## 처음 설정하기: 뒷면 탭 연결

뒷면 탭은 iOS 설정이라 앱이 대신 켤 수 없어요. 한 번만 직접 연결해 주세요.

1. 단축어 앱을 열고 + 를 눌러 새 단축어를 만들어요.
2. 동작 검색에서 '툭툭가계부'의 '지출 스택 남기기'를 추가하고, 이름을 '스택 남기기'로 저장해요.
3. 설정 › 손쉬운 사용 › 터치 › 뒷면 탭 › 이중 탭에서 맨 아래 '스택 남기기'를 골라요.
4. 결제 후 iPhone 뒷면을 두 번 톡톡 두드리면 스택이 저장되고 "스택을 남겼어요"가 표시돼요.

뒷면 탭 목록에는 단축어 앱에서 직접 만든 단축어만 보여요. 검색에 '툭툭가계부'가 나오지 않으면 툭툭가계부를 한 번 실행한 뒤 다시 찾아 주세요.

### 잠금화면·제어 센터에서 남기기 (iOS 18 이상)

1. 잠금화면을 길게 눌러 '사용자화'를 선택해요.
2. 잠금화면을 고른 뒤 아래쪽 컨트롤을 눌러 바꿔요.
3. 컨트롤 목록에서 '단축어'를 추가하고 '스택 남기기'를 선택해요.

제어 센터에도 같은 방법으로 추가할 수 있어요. 앱 안의 스택 탭 오른쪽 위 + 버튼으로도 스택을 남길 수 있어요.

## 하루 끝에 정리하기

1. 스택 탭에서 **모두 정리하기**를 눌러요.
2. 금액을 입력하고 카테고리를 고른 뒤 **저장하고 다음**을 누르면 다음 스택으로 넘어가요.
3. 지금 정리하기 어려운 스택은 **건너뛰기**로 넘기면 정리 대기 목록에 그대로 남아요. 결제가 아니었던 스택은 스택 탭 목록에서 왼쪽으로 밀어 삭제할 수 있어요.

정리한 기록은 내역과 통계 탭에 반영돼요. 정리하지 않은 스택은 합계에 포함되지 않아요.

## 뒷면 탭이 동작하지 않을 때

- 단축어 앱에서 '스택 남기기'를 직접 실행해 보세요. 여기서 저장되면 앱은 정상이고, 뒷면 탭 연결을 다시 확인하면 돼요.
- 설정 › 손쉬운 사용 › 터치 › 뒷면 탭 › 이중 탭에 '스택 남기기'가 선택되어 있는지 확인해 주세요.
- 두꺼운 케이스를 쓰면 뒷면 탭 인식이 잘 안 될 수 있어요. 케이스를 벗기고 한 번 확인해 보세요.

## 정리 알림이 오지 않을 때

정리 알림은 **정리하지 않은 스택이 있을 때만** 정한 시각에 와요. 모두 정리했다면 알림이 오지 않는 것이 정상이에요.

- 앱의 설정 › 정리 알림이 켜져 있고 알림 시각이 맞는지 확인해 주세요.
- iPhone 설정 › 알림 › 툭툭가계부에서 알림 허용이 켜져 있는지 확인해 주세요. 꺼져 있으면 앱의 스택 탭에 "정리 알림이 꺼져 있어요" 안내와 **알림 설정 열기** 버튼이 보여요.
- 집중 모드(방해 금지, 수면 등)가 켜져 있으면 알림이 조용히 전달될 수 있어요.

## 동네 이름이 보이지 않을 때

- 앱의 설정 › 위치에서 "스택에 위치 함께 저장"이 켜져 있고 위치 권한이 허용되어 있는지 확인해 주세요. 권한이 없어도 스택은 시각만으로 정상 저장돼요.
- 동네 이름은 인터넷에 연결되어 있을 때 Apple 지도 서비스로 확인해요. "장소 확인 대기 중"으로 보이면 앱을 다시 열 때 자동으로 다시 시도해요.
- "장소 확인 불가"로 보이면 정리 화면의 **장소 다시 확인**을 눌러 주세요. "위치 정확도 낮음"은 기록 당시 위치가 정확하지 않아 이름을 붙이지 않은 경우예요.

## 기록 백업과 복원

기록은 iPhone 안에만 저장되므로, 새 iPhone으로 옮기거나 앱을 지우기 전에는 직접 백업해 주세요.

1. 앱의 설정 › 데이터 › **기록 내보내기**를 눌러 JSON 파일을 파일 앱이나 iCloud Drive에 저장해요.
2. 복원할 iPhone에서 설정 › 데이터 › **기록 가져오기**를 누르고 저장해 둔 파일을 골라요.
3. 가져오기는 현재 기록을 파일 내용으로 **전체 교체**해요. 확인 화면에서 현재 기록을 먼저 내보낼 수 있어요.

iPhone 전체를 iCloud 백업이나 컴퓨터로 백업·복원하는 경우에도 앱 기록이 함께 옮겨질 수 있어요.

## 기록 삭제

- 설정 › 위치 › **저장된 위치 정보 모두 삭제**: 좌표와 동네 이름만 지우고 지출 기록은 남겨요.
- 설정 › 데이터 › **전체 데이터 삭제**: 모든 기록, 스택, 카테고리를 지우고 기본 카테고리만 다시 만들어요.
- 앱을 삭제하면 iPhone에 저장된 기록이 모두 함께 삭제돼요. 삭제한 기록은 되돌릴 수 없으니 필요하면 먼저 내보내 주세요.
